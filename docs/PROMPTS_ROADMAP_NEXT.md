Один промпт — один чат. В агент вставляйте только блок **Prompt**. Следующий шаг начинайте, когда предыдущий заархивирован и `:app:testDebugUnitTest` зелёный. Шаги 9–12 не начинайте, пока не заархивированы шаги 6 и 7.

Кадры Stitch уже лежат в наборе. HTML из них в `:app` не копировать. Кнопки «Старт» и «Пауза» в дырке круга уже иконки без подписи: слово на кнопку не возвращать.

## 6. Завершить задачу

Change: `complete-task-sheet`. Спеки: `flow-session`, `task-list`. Кадр: `_89`. Пустой каркас полей можно сверить с `_84`.

### Prompt

```
Роль: старший Android-разработчик (Kotlin 2, Compose, MVI). Правишь ClockPlanner, пакет com.example.clockplannerproject, один модуль :app.

Контекст: «Завершить задачу» уже закрывает перерыв, листа оценок нет. Оценки храни на деле, не внутри закрытого TimeBlock. Если поднимаешь схему Room — только version++ и fallbackToDestructiveMigration(), класса Migration нет, в ответе напиши, что локальная база сотрётся.

Цель: лист поверх приглушённого круга.
- Если у текущего дела нет названия — сначала его название. Иначе название только для чтения.
- Поле «Следующее дело». Пустое имя не создаёт следующее дело.

После сохранения оценки остаются на устройстве. Следующее дело появляется без открытого захода. Закрытые отрезки не меняются.

Acceptance:
- Пустое состояние не сохраняется, лист остаётся открытым.
- Безымянное дело получает имя, следующее дело появляется отдельно.
```
