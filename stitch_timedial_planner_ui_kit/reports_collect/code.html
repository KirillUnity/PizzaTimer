Отчёты

Заметки живут на устройстве

Сервер только составляет текст по присланному срезу и не хранит дневник. Сбор по расписанию без кнопки здесь не делается.

Неделя — семь местных дней, включая сегодня. Пустой день тоже успешный отчёт: в тексте будет сказано, что закрытых отрезков нет.

Подготовить отчёт

Ср, 4 ноя · 18:40

Закрыт шаг «Собрать цифры», 2 часа, статус выполнен. В принятом плане на сегодня стояла встреча 10:00–12:00 — она на месте. Сравнивать есть с чем: план и закрытые отрезки разошлись только по вычитке, её ещё нет.

Если принятого плана не было, заметка всё равно появляется и прямо говорит, что сравнивать не с чем.
